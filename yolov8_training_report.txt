1. SYSTEM ARCHITECTURE & DEMO SETUP (GROUND TRUTH)
--------------------------------------------------------------------------------
The physical demonstration was run directly on the Raspberry Pi, communicating 
wirelessly with the ESP32 robotic arm motion controller.

Physical Data Flow:
  [Conveyor Belt with E-Waste]
          |
          v
  [Camera Sensor (Connected to Raspberry Pi)]
          | - Color & Depth Frames (640 x 480 Resolution)
          v
  [Raspberry Pi Vision Processing Node]
          | - Multi-Scale FFT Normalized Cross-Correlation + Color Masking
          | - Spatial Depth Verification: Median depth (in mm) at target center
          v
  [Wireless Communication Link]
          | - Protocol: HTTP GET over 2.4 GHz Wi-Fi Hotspot (RoboArm-Hotspot)
          | - Target: http://192.168.4.1/cmd?act=pick_and_place
          v
  [ESP32 Motion Controller]
          | - Non-blocking smooth step interpolator (0.5° - 1.5° per 15 ms)
          v
  [6-DOF Robotic Arm Actuation]
          | - Base: 99° -> Shoulder: 84° -> Elbow: 124° -> Claw Grip: 131°
          | - Lift -> Rotate Base: 0° -> Claw Drop: 30° -> Return Home: 90°

Compute Note: The Raspberry Pi executed the computer vision pipeline and 
transmitted all automated trigger commands to the ESP32. Any laptop present 
in the demonstration served solely as a remote display / monitoring client.

2. TARGET CLASSES (PHYSICAL DEMO OBJECTS)
--------------------------------------------------------------------------------
The live sorting demonstration detects and sorts exactly three physical items:

1. 'Red circuit board' (PCB):
   - Visual Profile : Red FR4 solder mask, surface-mount components, pin headers
   - Color Filter   : (R - G > 35) & (R - B > 25)
   - Handling       : Rigid grasp across PCB perimeter

2. 'Cylindrical battery':
   - Visual Profile : Cylindrical form factor, metallic casing with dual-color wrap
   - Color Filter   : (R - G > 20) & (B - G > 15)
   - Handling       : Compliant grip limited to 131° to prevent casing damage

3. 'Seven-segment display':
   - Visual Profile : Rectangular LED display package, dark face with white segments
   - Handling       : Flat surface pick


--------------------------------------------------------------------------------
3. DATASET & DETECTION METHODOLOGY
--------------------------------------------------------------------------------
3.1 Reference Dataset ('references.npz'):
  The vision pipeline utilizes a verified reference dataset (references.npz) 
  generated directly from physical scans of the demo components:
  - Red circuit board    : 8 multi-scale template patches (Scales: 0.55x to 1.70x)
  - Cylindrical battery  : 5 multi-scale template patches
  - Seven-segment display: 4 multi-scale template patches
  - Total Reference Templates: 17 verified sub-image templates

3.2 Detection Algorithm:
  - Spatial resolution normalized to 240 px width maintaining aspect ratio.
  - 2D Fast Fourier Transform (FFT) frequency-domain normalized cross-correlation.
  - Energy normalization with rolling integral images (window_sum).
  - Dual-layer color verification masks to eliminate false positives from ambient shadows.
  - Depth map alignment: Reads median Z-depth (in mm) within the central patch of 
    each detected bounding box to confirm item presence on the conveyor.
